# Ringue ao Vivo

Interactive 3D fighting game for TikTok LIVE. Viewer gifts make the fighters punch.

- `index.ts`: the generated server, which Railway runs.
- `src/`: the sources. Edit them, then run `python3 src/build_repo.py` from a working copy that has `src/` files at its root.

Environment variables: `OPENAI_API_KEY` (AI chat replies) and `EULER_API_KEY` (optional).
